O que é

Custo efetivo por km, não preço bruto na bomba

Waze e Google mostram rota. Apps de preço mostram preço. Nenhum junta os dois com o perfil do veículo e o contexto de entrega urbana. O LogFree junta.

⛽ Custo real por km

Considera preço do litro, consumo (km/l) do veículo e o desvio de ida e volta até o posto — não só o preço na placa.

🤖 Bot Telegram

O motorista consulta pelo Telegram (onde ele já vive): envia localização e recebe o top posto recomendado, com auth por token de serviço.

🔒 Admin web com auditoria

Painel HTMX pra operador atualizar preço do dia, com login por sessão, CSRF, isolamento por cidade e trilha de auditoria em cadeia de hash.

Como funciona

Do pedido ao posto recomendado

Fluxo do endpoint principal POST /melhor-posto: recebe posição + combustível, calcula custo efetivo por posto ativo da cidade e devolve o ranking.

Motorista envia lat/lng + combustível→ Auth (sessão admin ou X-Bot-Token)→ Filtra postos ativos na bbox da cidade→ Calcula custo efetivo por km (Haversine)→ Ordena e retorna top N

📥 Entrada

Posição, combustível, autonomia restante e modo de abastecimento (completo/parcial), via API ou bot.

🧮 Cálculo

Distância até cada posto, litros do desvio, custo do desvio rateado pela capacidade do tanque, soma ao preço do litro.

📤 Saída

Top N postos por custo efetivo, com preço, distância, desvio e economia estimada vs. o mais próximo.

Só necessário se for testar o bot de verdade — sem ele, o webhook responde 503 e os testes seguem cobertos por mock.

Guia de uso · passo a passo

Do zero ao primeiro /melhor-posto

Comandos reais, na ordem em que o README do projeto recomenda rodar.

1

Setup local

Cria o venv, instala em modo dev e copia o `.env` de exemplo.

cd ~/projetos/logfree
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env  # pule o venv se já existir .venv
2

Banco + seed + admin

Roda as migrations, popula a cidade demo (15 postos, 6 combustíveis) e cria o primeiro usuário admin.

alembic upgrade head           # cria tabelas + triggers
python -m app.db.seed          # popula cidade_demo
logfree bootstrap-admin --email admin@local --password troca123-em-prod --cidade-id 1
3

Sobe o servidor

API + admin web num único processo Uvicorn, com reload em dev.

uvicorn app.api.main:app --host 0.0.0.0 --port 8000 --reload
# em outra aba, valide
curl http://localhost:8000/internal/ready
{"status":"ok"}
4

Bate no endpoint principal

Sem auth dá 401. Com o token de serviço do bot e o motorista demo do seed (telegram_id 100001), retorna o ranking.

curl -X POST http://localhost:8000/melhor-posto \
  -H 'Content-Type: application/json' \
  -H 'X-Bot-Token: dev-bot-token-change-me' \
  -H 'X-Bot-User-Telegram-Id: 100001' \
  -d '{
    "lat": -12.97, "lng": -38.50,
    "combustivel": "gasolina_comum",
    "autonomia_restante_km": 200,
    "modo_abastecimento": "completo",
    "top_n": 3
  }' | jq .
5

Admin web

Painel HTMX pra ver cidades, editar preço de posto e acompanhar métricas — login errado, CSRF ausente e cross-city são bloqueados e cobertos por teste.

http://localhost:8000/admin/login  # entre com admin@local + a senha do bootstrap
6

Testes e lint

~98 testes cobrindo API, admin e bot; ruff pro lint.

pytest -q                                   # todos
pytest tests/unit -q                        # só unitários
pytest tests/integration -q                 # API + admin + bot
pytest --cov=app --cov-report=term-missing  # com cobertura
ruff check app tests                        # lint
7

CLI de operação

Comandos operacionais: auditoria, break-glass, feature flags e replay pós-restore.

logfree audit-verify                                            # checa cadeia hash do evento_audit
logfree audit-unblock --approver=admin@x --motivo="..."         # break-glass (precisa AUDIT_UNBLOCK_KEY)
logfree flag-set --chave=ranking.osrm_enabled --valor=true
logfree flag-set --chave=kill_switch.global --valor=true        # desliga /melhor-posto (503)
logfree replay-tombstones                                       # pós-restore: re-anonimiza usuários tombstoned
8

Bot Telegram (opcional)

Só funciona com token real do BotFather. Exponha via ngrok e registre o webhook com o mesmo segredo no path e no header.

ngrok http 8000

# registrar webhook (mesmo segredo no path e no header)
curl "https://api.telegram.org/bot<TOKEN>/setWebhook" \
  -d "url=https://<seu-host-ngrok>/bot/webhook/$TG_WEBHOOK_SECRET" \
  -d "secret_token=$TG_WEBHOOK_SECRET"
